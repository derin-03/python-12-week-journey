# Simple Tip Calculator

## Algorithm
1. Start program
2. Ask user for bill amount
3. Ask user for tip percentage
4. Calculate tip amount
5. Calculate total bill
6. Display bill amount
7. Display tip percentage
8. Display tip amount
9. Display total bill
10. End program

## Description
This is a simple Python tip calculator that calculates total bill using the user's bill amount and tip percentage input.

## Features
1. Accepts user bill amount input
2. Accepts user tip percentage input
3. Calculates tip amount
4. Calculates total bill 

## Concepts Used
1. Variables
2. User input
3. Type conversion (float())
4. Arithmetic operators (+,/,-,*)

## How to Run
1. Open project in VS Code
2. Run `tip_calculator.py`
3. Enter your bill amount
4. Enter your tip percentage
5. View total bill
