# Mini Quiz Program (3 Questions)

## Algorithm
1. Start program  
2. Set score = 0  
3. Ask Question 1  
   - If answer is correct → score + 1  
4. Ask Question 2  
   - If answer is correct → score + 1  
5. Ask Question 3  
   - If answer is correct → score + 1  
6. Display total score  
7. Display performance message based on score  
8. End program  

## Description
This is a simple Python mini quiz program that asks the user 3 questions, tracks their score, and displays a final result based on performance.

## Features
1. 3 interactive quiz questions  
2. Score tracking system  
3. Performance feedback based on score  
4. Case-insensitive answer handling 
5. Input sanitization using `strip()`  

## Concepts Used
1. Variables  
2. User input  
3. Conditional statements (`if / elif / else`)  
4. String methods (`strip()`, `lower()`)  
5. Score tracking system  

## How to Run
1. Open project in VS Code  
2. Run `mini_quiz.py` or your file name  
3. Answer the questions  
4. View your final score and feedback
