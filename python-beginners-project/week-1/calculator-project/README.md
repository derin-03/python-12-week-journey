# Calculator Project

## Algorithm
1. Start program  
2. Display menu of operations  
3. User selects an operation (1–5)  
4. If choice is 1–4:
   - Ask for two numbers  
   - Perform calculation  
   - Display result  
5. If choice is 5:
   - Exit program  
6. Repeat until user exits  

## Description
This is a simple Python calculator that performs basic arithmetic operations using a loop. The program keeps running until the user chooses to exit.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Exit option (loop control using `break`)
- Handles division by zero error

## Concepts Used
- while loop
- if / elif / else conditions
- user input
- type conversion (float)
- break statement
- error handling (division by zero)
- user output

## How to Run
1. Open project in VS Code
2. Run `calculator.py`
3. Choose an operation
4. Enter numbers
5. Repeat or exit
