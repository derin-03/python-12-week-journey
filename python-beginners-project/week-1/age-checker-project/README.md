# Age Checker Program

## Algorithm
1. Start program  
2. Ask user for age input  
3. Convert input to integer  
4. Check age range:
   - If age is less than 0: print "Invalid age"
   - If age is between 0–12: print "You're a Child"
   - If age is between 13–19: print "You're a Teenager"
   - If age is between 20–59: print "You're an Adult"
   - If age is 60 and above: print "You're a Senior"
5. End program

## Description
This is a Python age checker program that determines a user's age category using conditional statements and comparison operators.

## Features
- Checks age category
- Handles invalid age input
- Uses conditional statements
