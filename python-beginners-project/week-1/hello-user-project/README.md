# HELLO USER INTERACTIVE PROGRAM

## Algorithm
1. Start program
2. Ask for user's name
3. Ask for user's age
4. Store input in variable
5. Display message

## Description
This is a simple Python interactive program that communicates with the user by asking for their name and age, then displays a personalized greeting.

## Features
1. Takes user input
2. Converts age input to integer
3. Displays personalized greeting message

## Concepts
1. User input
2. Variable
4. String output

## How to Run
1. Open project in VS Code
2. Run `hello_user.py`
3. Input your name
4. Press enter
5. Input your age
6. Press enter

## Source Code
All code is in `hello_user.py` inside this repository.
