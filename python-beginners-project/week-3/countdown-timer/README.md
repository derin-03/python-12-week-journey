# Countdown Timer (Python Project)

## Algorithm
1. Start program  
2. Ask user for time in seconds  
3. Convert input to integer  
4. While time is greater than 0:
   - Display current time
   - Reduce time by 1
   - Wait for 1 second
5. Display "Time's up!"  
6. End program  

## Description
This is a simple Python countdown timer that takes user input in seconds and counts down to zero with a 1-second delay between each number.

## Features
1. Accepts user input for countdown time  
2. Displays countdown in real time  
3. Uses delay to simulate a real timer  
4. Displays message when time ends  

## Concepts Used
1. Variables  
2. User input  
3. Integer conversion  
4. Loops (`while`)  
5. Time module (`time.sleep`)  
6. Decrement operation (`-=`)  

## How to Run
1. Open project in VS Code  
2. Run `countdown_timer.py`  
3. Enter number of seconds  
4. Watch countdown start  
5. Wait for "Time's up!" message
